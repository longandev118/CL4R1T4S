# 工作量评估导出脚本

从"项目规模评估 / 工作量评估"页面的表格里，把每一行的
**系统名称 / 负责人 / 外包人月** 抽取出来，按 Tab 分隔生成文本并复制到剪贴板，
方便直接粘贴到 Excel。

## 文件

| 文件 | 说明 |
| --- | --- |
| `workload-export.js` | 主脚本，可读、带注释，复制到控制台运行 |
| `workload-export.bookmarklet.txt` | 压缩后的书签版，保存成浏览器书签一键运行 |

## 用法一：控制台（推荐调试用）

1. 打开评估页面，按 `F12` 打开开发者工具，切到 **控制台 / Console**。
2. 把 `workload-export.js` 的内容整段粘贴进去，回车。
3. 内容已复制到剪贴板，去 Excel 里 `Ctrl+V` 粘贴。

想改导出的列，可再调用：

```js
exportWorkload({
  columns: ['系统名称', '负责人', '外包人月'], // 按表头名匹配
  sumColumn: '外包人月',                        // 需要合计的列
  tableIndex: 0,                                // 页面上第几个匹配表格
});
```

## 用法二：书签（一键运行）

1. 新建一个浏览器书签。
2. 把 `workload-export.bookmarklet.txt` 里的整行内容粘贴到书签地址栏。
3. 在评估页面点这个书签即可，内容会复制到剪贴板。

## 设计要点

- **按表头名定位列**，不写死列序号，页面列顺序变了也不会错位。
- 单元格取值优先级：`input.value` → `a/span` 文本 → 单元格纯文本。
- 自动跳过空行，自动合计 `外包人月` 并追加"合计"行。
- 复制优先用 DevTools 的 `copy()`，失败时回退到 `navigator.clipboard`，
  再失败则把内容打印到控制台供手动复制。
